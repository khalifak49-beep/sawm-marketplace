# منصة ساوم — نظام ربط المزارع بالوسيط والشركة

نظام ويب بـ **ASP.NET Core MVC 8** و **SQL Server (.\SQLEXPRESS)** يربط ثلاثة أطراف في دورة صفقة واحدة موثّقة:
المزارع ← الوسيط ← الشركة المشترية.

## التشغيل

```powershell
cd src\Sawm.Web
dotnet run
```

قاعدة البيانات `SawmDb` تُنشأ تلقائياً عند أول تشغيل (Migrate + Seed).
سلسلة الاتصال في `src/Sawm.Web/appsettings.json`:

```
Server=.\SQLEXPRESS;Database=SawmDb;Trusted_Connection=True;TrustServerCertificate=True
```

## حسابات تجريبية

كلمة المرور الموحدة: `Sawm@2026`

| الدور | البريد |
|---|---|
| مزارع | `farmer1@sawm.om` · `farmer2@sawm.om` · `farmer3@sawm.om` |
| وسيط | `broker1@sawm.om` · `broker2@sawm.om` |
| شركة | `company1@sawm.om` · `company2@sawm.om` |
| إدارة | `admin@sawm.om` |

## دورة الصفقة

1. **التسجيل** — ملف رقمي حسب الدور (مزرعة / وساطة / شركة).
2. **نشر العرض أو الطلب** — المزارع ينشئ مزاداً (لحظي أو مستقبلي)، والشركة تطرح مناقصة.
3. **اعتماد الوسيط** — المزاد يُنشأ بحالة "بانتظار الاعتماد"؛ باعتماده يصبح الوسيط مشرفاً عليه.
4. **المزايدة / تقديم العروض** — الشركات والوسطاء يزايدون؛ المزارعون والوسطاء يقدّمون عروضاً على المناقصات.
5. **الترسية** — تولّد عقداً رقمياً وتحسب العمولات تلقائياً.
6. **التوقيع الرقمي** من الطرفين ← العقد نشط.
7. **الضمان المالي** — المشتري يموّل حساب الضمان (احتجاز).
8. **التحقق الميداني** — الوسيط يسجّل تقرير جودة: مطابق / خصم متدرج / إحالة للتحكيم.
9. **الاستلام وتحرير الدفع** — تحويل الصافي للمزارع بعد خصم العمولات.
10. **التقييم المتبادل** — يحدّث سجل الموثوقية ويؤثر على المطابقة المستقبلية.

## العمولات

- **عمولة المنصة**: 2% افتراضياً (`ContractService.DefaultPlatformCommission`).
- **عمولة الوسيط**: من ملف الوسيط (`BrokerProfile.CommissionRate`)، افتراضي 2.5%.
- `صافي المزارع = القيمة الإجمالية − عمولة المنصة − عمولة الوسيط`

## حدود المسؤولية اللوجستية

المنصة **لا تنفّذ النقل ولا التخزين ولا التأمين**. الطرف المسؤول يُحدَّد في بند صريح داخل العقد،
مع سوق لوجستي مستقل (`/Logistics`) لنشر طلبات النقل واستقبال عروض المزودين.

## نظام التصميم

**النمط:** Trust & Authority — مناسب للمنصات المؤسسية التي تقوم على العقود والضمانات.
**اللوحة:** Agriculture/Farm Tech — أخضر الأرض + ذهبي الحصاد. **الكثافة:** لوحة تحكم (8/10).

| الرمز | القيمة | الاستخدام |
|---|---|---|
| `--primary-700` | `#15803D` | اللون الأساسي والروابط |
| `--primary-900` | `#14532D` | العناوين والنص الأساسي |
| `--accent` | `#A16207` | نداء العمل (ذهبي الحصاد) |
| `--bg` / `--card` | `#F0FDF4` / `#FFF` | الخلفية والبطاقات |
| `--grad-green` | `#0F3D21 → #14532D → #15803D` | البطل وأزرار الهوية |
| `--grad-sidebar` | `#0F3D21 → #14532D → #166534` | الشريط الجانبي |

**ملاحظة على التدرّجات:** درجات التدرّج مُختارة بحيث يبقى النص الأبيض فوق **أفتح نقطة** ضمن
WCAG AA. التدرّج الأصلي كان ينتهي عند `#22C55E` فيهبط التباين إلى `1.97:1` عند طرفه الفاتح —
لذلك أُغلقت التدرّجات عند درجات أغمق (`#15803D` = 5.02:1، `#166534` = 7.13:1).

### نظام الحركة

`wwwroot/js/motion.js` — مبني على **GSAP 3.12.5 + ScrollTrigger + jQuery**، والمكتبات مستضافة
محلياً في `wwwroot/lib/gsap` فيعمل النظام دون إنترنت.

| الحركة | التفاصيل |
|---|---|
| انتقال بين الشاشات | ستارة خضراء + خروج 160ms ودخول 280ms (الخروج أسرع ليبدو التنقل رشيقاً) |
| دخول الشريط الجانبي | انزلاق + تتابع الروابط 35ms، وشعار يرتد `back.out` |
| بطاقات المؤشرات | ظهور متتابع + عدّاد تصاعدي للأرقام |
| كشف عند التمرير | أقسام `.reveal` تظهر عند بلوغها 92% من الشاشة |
| رسم الأيقونات | `stroke-dashoffset` يرسم أيقونات SVG عند ظهورها |
| تفاعلات دقيقة | تموّج عند الضغط، رفع البطاقات، دوران الأيقونات، حدود متدرّجة متحركة |

**ثلاثة دروس مكلفة تعلّمناها هنا — موثّقة كي لا تتكرر:**

1. **لا تُحرّك عنصراً بتَينَين متنافسين.** عنصر داخل حركة الدخول و`.reveal` معاً كان يعلق عند `opacity:0`.
2. **`clearProps:'all'` تمسح سمة `style` بالكامل.** قسم نداء العمل فقد تدرّجه فصار نصه الأبيض غير مرئي —
   لذلك انتقل تنسيقه إلى الصنف `.cta-band`. **لا تعتمد أنماطاً سطرية على عنصر تُحرّكه GSAP.**
3. **الجداول بيانات لا زينة.** `gsap.from` يطبّق `autoAlpha:0` فوراً، فبقيت صفوف عقود مكتوبة
   بالكامل غير مرئية على شاشة الجوال حتى التمرير. صفوف الجداول تُحرَّك بالموضع فقط بلا إخفاء.

بالإضافة إلى شبكة أمان تُظهر أي عنصر يبقى مخفياً بعد 2.5 ثانية، و`<noscript>` يُخفي الستارة
عند تعطيل جافاسكربت.

- **الخط:** IBM Plex Sans Arabic مستضاف محلياً في `wwwroot/fonts` — لا اعتماد على CDN، يعمل دون إنترنت.
- **الأيقونات:** SVG خطي مضمّن عبر `Services/Icons.cs` (`Icons.Render("name")`) — لا إيموجي.
- **الإتاحة:** تباين AA على كل الصفحات، أهداف لمس ≥ 34px، حلقة تركيز ظاهرة، دعم `prefers-reduced-motion`.

## ملاحظات تقنية

- الهوية والأدوار عبر ASP.NET Core Identity (`Farmer` / `Broker` / `Company` / `Admin`).
- العلاقات على `AspNetUsers` تستخدم `DeleteBehavior.Restrict` لتفادي مسارات الحذف المتعددة في SQL Server.
- `NotificationService` هو نقطة الوصل المستقبلية مع واتساب للأعمال — حالياً إشعارات داخلية.
- كل تغيّر في حالة العقد يُسجَّل في `ContractEvents` كسجل تدقيق كامل.
